# 05_emp_prob_jep_calculation

## Folder Title

Empirical Joint Exceedance Probability Calculation

## Purpose of the Folder

This folder contains MATLAB scripts used to estimate empirical exceedance probabilities for moisture-driven landslide (MDL) events across the Northeastern Himalayas (NEH).

The scripts calculate the AND-based trivariate joint exceedance probability (JEP) of triggering rainfall (TR), antecedent moisture condition represented by API, and lagged root-zone effective saturation (`S_eff`). The folder also compares the trivariate JEP against the TR-only exceedance probability.

## Scientific Relevance to the Manuscript

The scripts support the manuscript’s compound-triggering analysis by quantifying the simultaneous exceedance of TR, AMC/API, and lagged `S_eff`. This provides a probabilistic measure of how rainfall triggering, antecedent wetness, and root-zone saturation jointly condition MDL likelihood.

The trivariate JEP is used as a more restrictive compound-triggering likelihood than TR-only exceedance probability and supports LEWS-oriented interpretation of wetness-conditioned MDL hazard.

## Scripts Included

1. `calculation_jep_&_uni.m`
2. `plot_trivariate_emP_prob_final_with_uni_variate_v3.m`

## Brief Description of Scripts

### `calculation_jep_&_uni.m`

Calculates empirical exceedance probabilities for selected representative MDL events at each station.

The script reads station-wise event data containing TR, API, `S_eff`, landslide size, event year, and distance from the station. It converts TR, API, and `S_eff` into rank-based non-exceedance probabilities and estimates pairwise and trivariate empirical copula terms.

The main output is the AND-based trivariate JEP:

`JEP = P(TR > tr0, API > api0, S_eff > seff0)`

The script also calculates TR-only exceedance probability and the ratio of trivariate JEP to TR-only exceedance probability.

### `plot_trivariate_emP_prob_final_with_uni_variate_v3.m`

Generates a diagnostic figure comparing trivariate JEP and TR-only exceedance probability against terrain slope.

The script uses station-wise metadata such as slope, built-up area, vegetation fraction, and selected landslide year. It applies bootstrap regression to compare the slope dependence of trivariate JEP and TR-only exceedance probability.

## Required Input Files

The scripts require the following input files:

* Station-wise MDL event workbook containing TR, API, `S_eff`, landslide size, event year, and distance from station.
* NEH station metadata file containing station ID, station name, slope, built-up area, and vegetation fraction.
* Empirical probability output file generated by the JEP calculation script.

File paths are defined inside the scripts and should be updated by the user before running.

## Expected Output Files

The scripts generate the following outputs:

* Station-wise table of selected MDL events.
* Rank-based non-exceedance probabilities for TR, API, and `S_eff`.
* Exceedance probabilities for TR, API, and `S_eff`.
* Pairwise empirical copula terms.
* Trivariate empirical copula term.
* AND-based trivariate JEP.
* TR-only exceedance probability.
* Ratio of trivariate JEP to TR-only exceedance probability.
* Figure comparing trivariate JEP and TR-only exceedance probability with terrain slope.
* Bootstrap slope estimates and 95% confidence intervals.

## Recommended Run Order

1. Ensure that station-wise event data are available with TR, API, lagged `S_eff`, landslide size, distance, and event year.
2. Ensure that station metadata include slope, built-up area, and vegetation fraction.
3. Run `calculation_jep_&_uni.m` to calculate empirical trivariate JEP and TR-only exceedance probability.
4. Run `plot_trivariate_emP_prob_final_with_uni_variate_v3.m` to generate the probability comparison figure and bootstrap regression diagnostics.

## Notes on Reproducibility

* The scripts use rank-based pseudo-observations to estimate empirical non-exceedance probabilities.
* The trivariate JEP calculation follows an AND-based simultaneous-exceedance framework.
* The selected representative MDL event at each station is chosen based on landslide size, with distance used as a secondary criterion when multiple events share the same size class.
* Bootstrap regression uses a fixed random seed for reproducibility.
* Users should verify file paths, station sheet names, column names, and metadata fields before running.

## Assumptions and Methodological Notes

* TR represents the rainfall event immediately associated with the MDL.
* API represents rainfall-derived AMC at the relevant antecedent lag.
* `S_eff` represents lagged root-zone effective saturation.
* Rank-based pseudo-observations are used to represent empirical marginal distributions of TR, API, and `S_eff`.
* The empirical copula framework is used to account for dependence among TR, API, and `S_eff`.
* The AND-based trivariate JEP estimates the probability that TR, API, and `S_eff` jointly exceed their event-specific thresholds.
* TR-only exceedance probability is retained as a rainfall-only reference condition.
* Comparing trivariate JEP with TR-only exceedance helps assess how compound wetness conditioning modifies MDL likelihood.
* Terrain slope, built-up area, and vegetation fraction are used for diagnostic interpretation of spatial variability in exceedance probabilities.
